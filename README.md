## Описание задачи
Проект представляет собой библиотеку для работы с матрицами на языке C++17. 
Реализованы базовые операции (создание, удаление, сложение, умножение, вывод), 
а также индивидуальное задание: подсчет элементов, модуль которых превышает заданный порог.

## Способ обработки ошибок
В проекте используется механизм **исключений C++** (`std::invalid_argument`, `std::bad_alloc`). 
Это позволяет корректно обрабатывать некорректные размеры матриц и ошибки выделения памяти, 
не приводя к сбою программы (segfault).

## Структура проекта и реализованные функции
*   `include/matrix.h` — заголовочный файл с объявлениями функций и Doxygen-комментариями.
*   `src/matrix.cpp` — реализация функций:
    *   `create_matrix` — создание матрицы и выделение памяти.
    *   `free_matrix` — освобождение памяти (защита от утечек).
    *   `matrix_add` — сложение матриц.
    *   `matrix_multiply` — умножение матриц.
    *   `print_matrix` — форматированный вывод.
    *   `matrix_from_array` — инициализация из одномерного массива.
    *   `matrix_count_nonzero` — **индивидуальное задание (Вариант 29)**.
*   `src/main.cpp` — точка входа, демонстрация работы библиотеки.
*   `tests/test_matrix.cpp` — unit-тесты (Google Test).

## Инструкция по сборке и запуску
Для сборки требуется CMake (версия 3.20+) и компилятор с поддержкой C++17.

```bash
# Сборка проекта
cmake -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel $(nproc)

# Запуск основной программы
./build/matrix_calculator

# Запуск тестов
cd build && ctest --verbose
